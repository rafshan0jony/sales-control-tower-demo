# Sales Control Tower — Demo

A full-stack sales analytics & management dashboard (a portfolio demo built by
**Rafshan Jony**). This is a **self-contained demo** with 100% fake data — no
real company, customer, or credentials are included.

## Features

- Role-based dashboard (National / Region / Area / Territory officers)
- Target vs Achievement (by territory and by product)
- Sales orders, deliveries, pending orders, and customer credit status
- Insights & recommendations
- Tour plan / daily sales report (field entry)
- Territory hierarchy & user management (admin panel)

## Tech stack

- Node.js + Express (backend API)
- SQLite (`node:sqlite`) for metadata + snapshot storage
- Vanilla JS SPA frontend (Chart.js for charts)
- JWT authentication with role-based access control

## Run locally

```bash
# 1. install dependencies
npm install

# 2. generate + seed the demo data (fake territories, customers, orders, etc.)
node demo/seed.js

# 3. start the server
npm start
```

Then open <http://localhost:8080>.

## Deploy to Vercel

The repo is Vercel-ready (`vercel.json` + `api/index.js`). On Vercel the demo
data is auto-seeded into an ephemeral `/tmp` database on first request.

```bash
vercel        # or connect the repo in the Vercel dashboard
```

- No external services (ERP, Google Sheets, Google Chat) are required.
